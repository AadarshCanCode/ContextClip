# ContextClip HyperFrames Demo

Create a short self-contained product demo video for ContextClip using HyperFrames. The video should show a real desktop copy flow: dashboard context appears, the copy bubble opens near the copied context, and actions such as Calendar, Task, and References become available.

## Constraints

- Use HyperFrames HTML with deterministic GSAP animation.
- Avoid remote media assets and credentials.
- Render a local MP4.
- Keep the demo focused on the app workflow, not a generic marketing page.
